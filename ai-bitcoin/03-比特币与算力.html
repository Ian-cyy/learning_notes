03 · 比特币与算力

账本 → 哈希 → 挖矿题目 → 完整流程 → 防作弊 → 发行 → 私钥 → 硬件 → 与 AI 算力对比

一比特币是什么

比特币（Bitcoin，BTC）是一个 去中心化的数字货币系统：

  • 没有央行：谁都不能印钞。
  • 没有银行：你持有的是私钥（密钥），不是"账户余额"。
  • 账本公开：谁都能下载、查看、验证全部历史交易。
  • 发行靠"挖矿"：用算力解决数学题来获得新币。
比特币 = 一套"用密码学 + 工作量证明（PoW）"实现去中心化记账的系统。

二区块链：公开账本

2.1 记账的方式

区块 0（创世块）
  │ 记录最早的交易 + 区块哈希
  ▼
区块 1
  │ 记录新交易 + 上一个区块的哈希
  ▼
区块 2
  │ 记录新交易 + 上一个区块的哈希
  ▼
区块 3 → 区块 4 → …（一条链）

2.2 区块链三个特性

  • 公开：全部记录公开可见。
  • 不可篡改：改任一区块，后面所有区块的哈希全对不上。
  • 去中心化：没有唯一服务器，账本在成千上万节点上复制。

三SHA-256：把任意数据变成"指纹"

SHA-256 = 输入任意数据 → 输出固定 256 位（64 个十六进制字符）的"哈希值"。
  • 确定性：同样的输入 → 同样的输出。
  • 单向性：有输出算不出输入（只能暴力试）。
  • 雪崩效应：改一丁点输入，输出面目全非。
  • 防碰撞：几乎找不到两个不同输入得到同一输出。
  • 例：SHA256("123") → a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3
💡 为什么要"哈希"账本
把每个区块做成"指纹"，形成链条；想改一笔旧账，就得重新伪造所有后续指纹——几乎不可能。

四挖矿的"题目"是什么

把 区块头信息 + 一个随机数 nonce 一起做 SHA-256：

目标：找到 nonce，使 SHA256( 区块头 + nonce ) 的结果 小于目标值（前若干位是 0）。
  • 题目没有"会解"的聪明方法：只能一个个试 nonce（暴力猜）。
  • 试了几万亿次，终于试到一个符合条件 → 这个区块就算"挖"出来了。
🌰 类比
像掷骰子：要求"掷出 6 才有资格记账"，全世界的矿工一起掷，谁先掷出 6 谁记账并拿奖励。

五挖矿完整流程

1. 收集内存池里的待确认交易
2. 打包成一个"候选区块"
3. 疯狂试 nonce：
      SHA256(区块头 + nonce)  <  目标值 ？
      ✗ → nonce+1 继续试
      ✓ → 停止，广播这个区块
4. 其他节点验证（秒级）：
      检查题目确实满足 + 交易合法
5. 验证通过 → 区块上链
6. 矿工获得：区块奖励 + 手续费
  • 难度自动调整：全网算力涨 → 题目更难；算力跌 → 题目更易。每 2016 个区块调整一次，目标是保持约 10 分钟出一个块。

六为什么"验证"一眼就行

挖矿（找答案）验证（查答案）
难度极难（暴力搜索）极容易
做法试几万亿次把答案代入算一次
计算量天文数字一次 SHA-256，毫秒级
类比煎一整桌菜尝一口就知道熟没熟
哈希的性质决定了"解题难、验证易"——这正是 PoW 能用的根基。

七为什么安全、为什么防作弊

7.1 为什么防作弊

  • 伪造一笔不存在的交易，或双花 → 必须重算那笔交易之后的全部区块。
  • 全网都在不停挖新块，作弊者要一直比全网快 —— 算力不够？永远追不上。
  • 理论攻击：拥有 全网 51% 以上算力才可能篡改（"51% 攻击"），代价高得离谱。

7.2 哈希在其中的角色

哈希特性保障什么
单向性出题容易、破解难
雪崩效应篡改立刻现形
防碰撞不能伪造另一份"看起来一样"的数据
链式结构改一处 = 重写后面整条链

八挖矿算力是不是"白费"

两种观点，本质是成本与信任之争：

观点理由
❌ 浪费能源几十万亿美元级算力只用来猜数，太浪费
✅ 必要成本正是这笔"买算力的钱"让作弊变得无利可图 → 安全 → 有人信
📌 更准确的理解
挖矿的产出不是"正确答案"，而是全网认可的"记账权"和"信任"。就像金矿挖出的黄金本身"没用"，但共识认为它值钱。

九发行机制：2100 万 · 减半 · 2140

规则内容
总量上限 2100 万个（数学硬顶）
出块奖励每 4 年减半：50 → 25 → 12.5 → 6.25 → 3.125 → …
出块间隔约 10 分钟一个块（难度自动调整）
挖完时间约 2140 年挖完最后一枚
  • 奖励越来越小，新币增速放缓 → 稀缺性上升。
  • 2140 年后无区块奖励，矿工靠 手续费 生存。

十钱归谁：私钥与公钥

公钥 / 地址私钥
是什么公开的"收款账号"绝密的"签名钥匙"
给别人✅ 可以❌ 绝对不行
作用收款签名、转账
丢了没事钱永远没了
⚠️ 铁律
谁有私钥，谁就是主人。私钥丢了 = 币没了，没有任何机构能帮你找回（这正是"去中心化"的代价）。

十一挖矿硬件：GPU 早已出局

时间线

阶段设备
2009 早期CPU（个人电脑）
2010~2012GPU（比 CPU 快几十倍）
2013~2014FPGA / 第一代 ASIC
2014 至今专业 ASIC 矿机（Antminer 等）

为什么 GPU 出局

  • SHA-256 就是极简单、极重复的运算 → 专用芯片（ASIC）能比 GPU 快 数百到上千倍、功耗低得多。
  • 比特币已经是 ASIC 的天下，GPU 挖 BTC 毫无性价比。
  • GPU 现在去挖 抗 ASIC 的小币种（ETH 转 PoS 后这类需求减少），或者转投 AI。
有意思的反差：GPU 靠"算得又快又准"在 AI 吃香，却在比特币这里被更"笨但更专"的 ASIC 淘汰。

十二比特币 vs AI：算力之争

维度比特币挖矿AI 训练/推理
核心运算SHA-256 哈希矩阵乘法（GEMM）
需求本质暴力猜数海量并行数学
硬件ASIC（专用）GPU/TPU/NPU（通用）
有没有"聪明解法"没有，只能硬算有算法/架构优化空间
进步方向更快更省电地"猜"更聪明地"算"（并行、精度、算法）
产出记账权 + 币模型参数 + 智能

会不会互相抢算力

  • ASIC 挖不了 AI（只能做哈希）；GPU 挖 BTC 没性价比。
  • 两种算力不完全互通，但都抢电力、先进产能、芯片制造资源。

十三一句话总纲

比特币是"用算力换共识"的系统：哈希让出题难、验证易，PoW 让作弊代价高到不可能；总量 2100 万、每 4 年减半、约 2140 年挖完；私钥即所有权。它和 AI 都吃算力，但一个在"无脑猜数"上卷到 ASIC 极致，一个在"海量矩阵并行"上不断做聪明优化——同为算力，两种活法。

零为什么要自定义接口 + 串口节点

  • std_msgs/String 只能发字符串；真实机器人要发结构化数据（速度、状态、模式）。
  • msg = 话题的数据格式；srv = 一问一答；action = 长任务（带进度、可取消）。
  • 串口节点 = 把"ROS2 话题"翻译成"下位机协议帧"的桥：
ROS2 上层                          下位机（F407）
/motor_cmd (MotorCmd) ──┐
                        ├─ 串口节点(serial_bridge) ── 0xCC帧 ──> 电机
/robot_status (RobotStatus) <─┘
💡 一句话
话题是"接口"，0xCC 帧是"协议"，串口节点就是两者之间的翻译官。

二自定义 msg 的发布 / 订阅

先在 python_launch_demo/package.xml 加 <exec_depend>robot_interfaces</exec_depend>。

pythonimport rclpy
from rclpy.node import Node
from robot_interfaces.msg import MotorCmd


class MotorCmdPub(Node):
    def __init__(self):
        super().__init__('motor_cmd_pub')
        self.pub = self.create_publisher(MotorCmd, 'motor_cmd', 10)
        self.create_timer(1.0, self.tick)

    def tick(self):
        msg = MotorCmd()
        msg.vx, msg.vy, msg.wz = 0.2, 0.0, 0.0
        self.pub.publish(msg)
        self.get_logger().info(f'发指令 vx={msg.vx:.2f} vy={msg.vy:.2f} wz={msg.wz:.2f}')


def main():
    rclpy.init()
    node = MotorCmdPub()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()

三自定义 srv（服务 / 客户端）

pythonimport rclpy
from rclpy.node import Node
from robot_interfaces.srv import SetMode


class SetModeServer(Node):
    def __init__(self):
        super().__init__('set_mode_server')
        self.srv = self.create_service(SetMode, 'set_mode', self.handle)
        self.mode = 0

    def handle(self, request, response):
        if request.mode in (1, 2, 3, 4):
            self.mode = request.mode
            response.success, response.message = True, f'模式切换为 {request.mode}'
        else:
            response.success, response.message = False, f'非法模式 {request.mode}'
        self.get_logger().info(response.message)
        return response


def main():
    rclpy.init()
    node = SetModeServer()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()

四自定义 action（长任务）

pythonimport time
import rclpy
from rclpy.action import ActionServer
from rclpy.executors import MultiThreadedExecutor
from rclpy.node import Node
from robot_interfaces.action import MoveDistance


class MoveDistanceServer(Node):
    def __init__(self):
        super().__init__('move_distance_server')
        self._server = ActionServer(self, MoveDistance, 'move_distance', self.execute_cb)

    def execute_cb(self, goal_handle):
        target = goal_handle.request.distance
        traveled, step, dt = 0.0, 0.05, 0.1
        feedback = MoveDistance.Feedback()
        while traveled < target:
            if goal_handle.is_cancel_requested:
                goal_handle.canceled()
                result = MoveDistance.Result(); result.finished, result.traveled = False, traveled
                return result
            traveled += step
            feedback.remaining = max(0.0, target - traveled)
            goal_handle.publish_feedback(feedback)
            time.sleep(dt)
        goal_handle.succeed()
        result = MoveDistance.Result(); result.finished, result.traveled = True, traveled
        return result


def main():
    rclpy.init()
    node = MoveDistanceServer()
    executor = MultiThreadedExecutor()   # 否则 time.sleep 期间收不到"取消"
    executor.add_node(node)
    try:
        executor.spin()
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
bashros2 run python_launch_demo move_distance_server
ros2 run python_launch_demo move_distance_client
ros2 action send_goal /move_distance robot_interfaces/action/MoveDistance "{distance: 2.0}" --feedback
💡 要点
action = goal + result + feedback，可取消；导航/抓取这类长任务用它。真实代码别用 time.sleep，用定时器 + 状态机（这里为演示直观）。

五串口节点 serial_bridge ★重头戏

5.1 依赖（apt，不要只用 pip）

bashsudo apt install python3-serial
python3 -c "import serial; print(serial.__version__)"

5.2 教学协议

帧: 0xCC | TYPE | LEN | DATA | CRC8(0x07) | 0x55
  TYPE 0x01 HEARTBEAT  无数据
  TYPE 0x10 MOTOR_CMD  DATA = vx,vy,wz (int16 大端, mm/s)
  TYPE 0x11 STATUS     DATA = battery(uint8 %) + mode(uint8)

5.3 serial_bridge.py（节选）

pythonimport struct, threading
import rclpy
import serial
from rclpy.node import Node
from robot_interfaces.msg import MotorCmd, RobotStatus

HEAD, TAIL = 0xCC, 0x55
TYPE_HEARTBEAT, TYPE_MOTOR_CMD, TYPE_STATUS = 0x01, 0x10, 0x11


def crc8(data: bytes) -> int:
    crc = 0
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = ((crc << 1) ^ 0x07) & 0xFF if crc & 0x80 else (crc << 1) & 0xFF
    return crc


def build_frame(typ: int, data: bytes = b"") -> bytes:
    body = bytes([typ, len(data)]) + data
    return bytes([HEAD]) + body + bytes([crc8(body), TAIL])


class SerialBridge(Node):
    def __init__(self):
        super().__init__('serial_bridge')
        self.declare_parameter('port', '/dev/ttyUSB0')
        self.declare_parameter('baud', 115200)
        port = self.get_parameter('port').value
        baud = self.get_parameter('baud').value
        self.ser = serial.Serial(port, baud, timeout=0.05)

        self.status_pub = self.create_publisher(RobotStatus, 'robot_status', 10)
        self.create_subscription(MotorCmd, 'motor_cmd', self.on_cmd, 10)
        self.create_timer(1.0, self.send_heartbeat)

        self.rx_buf = bytearray()
        self.running = True
        self.rx_thread = threading.Thread(target=self.read_loop, daemon=True)
        self.rx_thread.start()

    def on_cmd(self, msg: MotorCmd):
        data = struct.pack('>hhh', int(msg.vx * 1000), int(msg.vy * 1000), int(msg.wz * 1000))
        self.ser.write(build_frame(TYPE_MOTOR_CMD, data))

    def send_heartbeat(self):
        self.ser.write(build_frame(TYPE_HEARTBEAT))

    def read_loop(self):
        while self.running and rclpy.ok():
            chunk = self.ser.read(64)
            if chunk:
                self.rx_buf += chunk
                self.parse_frames()

    def parse_frames(self):
        while len(self.rx_buf) >= 5:
            if self.rx_buf[0] != HEAD:              # 对齐帧头
                self.rx_buf.pop(0)
                continue
            length = self.rx_buf[2]
            total = length + 5
            if len(self.rx_buf) < total:            # 不够一帧
                return
            frame = bytes(self.rx_buf[:total])
            del self.rx_buf[:total]
            if frame[-1] != TAIL:                   # 帧尾错
                continue
            if crc8(frame[1:3 + length]) != frame[3 + length]:   # CRC 错
                continue
            self.handle_frame(frame[1], frame[3:3 + length])

    def handle_frame(self, typ, data):
        if typ == TYPE_STATUS and len(data) >= 2:
            msg = RobotStatus()
            msg.battery, msg.mode, msg.online = float(data[0]), int(data[1]), True
            self.status_pub.publish(msg)

    def destroy_node(self):
        self.running = False
        if self.ser.is_open:
            self.ser.close()
        super().destroy_node()
💡 要点
  • 发：订阅回调里打包帧写串口；收：后台线程读 + 状态机断帧；
  • 端口/波特率做成 parameter；心跳定时器（对应 F407 的 3s 超时保护）。

十与真实项目对照（救援机器人 ROS2）

上面的练习是教学版（假协议 0x10/0x11）。真实工程 ~/ros2_ws 的接口与桥：

10.1 真实的 robot_interfaces（本练习的"本尊"）

类型文件字段
msgArmJointCmd.msgq1..q6(int16) + pid + repeats（→ F103 0xAA）
msgTargetPos.msgheader + x + y + id + valid（视觉目标）
msgBallOrder.msgheader + uint8[] order（球出现顺序）
msgF407Event.msgevent + mode（含常量 SET_MODE/ALIGNED/ABORT）
srvSetMode.srvmode → accepted
srvSelectTarget.srvid + color → ok
srvSetResolution.srvwidth + height → ok
srvArmSeq.srvpose + repeats → ok（发录制姿态帧）

特点：真实项目只用 msg + srv，没有 action（流程靠"话题驱动 + 状态机"）。

10.2 串口节点 = 我们的 f407_bridge / arm_bridge

  • 练习里的 serial_bridge（话题↔0xCC）就是真实工程的 f407_bridge：订阅 /f407/pos,/done,/backup → 打包 0xCC 帧；后台线程读串口 → protocol.py 断帧+CRC8 → 发 /f407/events。
  • arm_bridge 同理（话题 /arm/cmd,/arm/seq ↔ 0xAA 关节帧，q3/q4 取反，连发防丢）。
  • 真实 0xCC 帧：CC | TYPE | LEN | DATA | CRC8(0x07) | 55；TYPE 有 HEARTBEAT/SET_MODE/ALIGNED/ABORT/POS(id)/DONE/BACKUP/ARM_REPORT。

10.3 为什么真实项目用 msg/srv、不用 action

  • 车/臂的控制是周期性、事件驱动（POS 25Hz、SET_MODE 事件、DONE 事件）→ msg + srv 足够；
  • action 适合"一个可取消的长任务"（如"走2米带进度"），我们的 20 段路径是 F407 侧状态机在跑，Pi 只发事件/坐标 → 不需要 action；
  • 练习里写 action 是为了掌握 ROS2 全套接口（面试常问），实际项目按需选型。

练习里手写的 robot_interfaces + serial_bridge，就是真实工程 robot_interfaces + f407_bridge/arm_bridge 的 简化教学版；学完这份，读真机代码就通了。

二我写的代码

1.1 talker.py（带参数回调，最终版）

import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from rcl_interfaces.msg import SetParametersResult


class Talker(Node):
    def __init__(self):
        super().__init__('talker')
        self.declare_parameter('msg', 'hello,ros2')
        self.declare_parameter('rate_hz', 1.0)
        self.pub = self.create_publisher(String, 'chatter', 10)
        rate = self.get_parameter('rate_hz').value
        self.timer = self.create_timer(1.0 / rate, self.tick)
        self.add_on_set_parameters_callback(self.on_param_change)
        self.count = 0

    def on_param_change(self, params):
        for p in params:
            self.get_logger().info(f'参数改变:{p.name} = {p.value}')
            if p.name == 'rate_hz':
                self.timer.cancel()
                self.timer = self.create_timer(1.0 / p.value, self.tick)
            elif p.name == 'msg':
                pass
        return SetParametersResult(successful=True)

    def tick(self):
        text = f"{self.get_parameter('msg').value} #{self.count}"
        self.pub.publish(String(data=text))
        self.get_logger().info(f'publish : {text}')
        self.count += 1


def main():
    rclpy.init()
    node = Talker()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
💡 要点
  • declare_parameter 声明（默认 1.0）
  • 回调里 rate_hz 变化 → timer.cancel() + 重建（这样才真正生效）
  • msg 每次 tick 重新读 → 改文字自动生效，不需要重建什么
  • 返回 SetParametersResult(successful=True)；返回 False 可拒绝修改

1.2 config/talker.yaml

/talker:
  ros__parameters:
    msg: "from yaml"
    rate_hz: 2.0
💡 要点
  • /talker: 节点全名，必须和 Node 的 name 一致（不一致会静默忽略）
  • ros__parameters 是双下划线
  • 缩进用空格

1.3 launch/06_cfg_yaml_from.launch.py

from launch import LaunchDescription
from launch_ros.actions import Node
from launch.substitutions import PathJoinSubstitution
from launch_ros.substitutions import FindPackageShare


def generate_launch_description():
    return LaunchDescription([
        Node(
            package='python_launch_demo',
            executable='talker',
            name='talker',
            output='screen',
            parameters=[
                PathJoinSubstitution([
                    FindPackageShare('python_launch_demo'), 'config', 'talker.yaml',
                ]),
                {'rate_hz': 3.0},        # ← 字典在后面, 覆盖 YAML
            ],
        )
    ])

三实操步骤与验证结果

第 1 步：声明 + 读取

ros2 run python_launch_demo talker     # 1Hz, "hello,ros2 #n"

第 2 步：命令行查看/修改

ros2 param list /talker                # msg, rate_hz, use_sim_time
ros2 param get /talker rate_hz         # 1.0
ros2 param set /talker rate_hz 5.0     # 值变 5.0
ros2 param get /talker rate_hz         # 5.0 ← 值确实改了
★ 关键观察
值改成 5.0 了，但发布频率还是 1Hz → "set 成功 ≠ 行为改变"（原因：timer 只在 __init__ 里创建过一次）

第 3 步：参数回调（真正生效）

加上回调后重新 build：

ros2 param set /talker rate_hz 5.0
# 终端打印: 参数改变:rate_hz = 5.0
# 频率立刻变 5Hz ✅
ros2 param set /talker msg world
# 下一条消息: "world #n" ✅（msg 每 tick 重读，本来就即时）

第 4 步：YAML 文件

# 注意路径：相对路径是相对"当前目录"的
ros2 run python_launch_demo talker --ros-args --params-file src/python_launch_demo/config/talker.yaml
# 输出: "from yaml #n", 2Hz ✅

第 5 步：launch 加载 YAML

ros2 launch python_launch_demo 06_cfg_yaml_from.launch.py
# 输出: "from yaml #n", 3Hz ✅（msg 来自 YAML，rate_hz 被字典覆盖）

第 6 步：dump / load

ros2 param dump /talker > /tmp/talker_saved.yaml
ros2 param load /talker /tmp/talker_saved.yaml

四参数优先级（实测结论）

六踩坑记录（本次实际遇到）

#现象原因解决
1Error opening YAML file（Failed to parse global arguments）--params-file config/talker.yaml 是相对路径，当前目录是工作空间根目录，没有这个文件用 src/python_launch_demo/config/talker.yaml，或先 cd 到包目录
2launch 加载 YAML 找不到文件setup.py 没注册 config 目录，install 空间没有 config/data_files 加 (os.path.join('share', package_name, 'config'), glob('config/*.yaml')) + 重新 build
3set 后 get 是 5.0，但频率没变参数值变了，但 timer 只在 __init__ 创建一次，没人读新值加 on_set_parameters_callback 重建 timer
4新开的 talker 还是 1.0① 参数是每个节点实例私有；② 新实例用 declare 默认值启动想以非默认值启动：-p rate_hz:=5.0 或 YAML/launch
5改了 setup.py / 新增文件后命令没变化没重新 build / 没 sourcecolcon build --symlink-install && source install/setup.bash
⚠️ 易踩但本次没踩的坑（记住）
  • ros__parameters 写成单下划线 → 静默失效
  • YAML 的节点名 /talker 和 Node 的 name 不一致 → 静默忽略
  • YAML 里 rate_hz: "2.0"（带引号）→ 字符串类型不匹配
  • rate_hz 被设成 0/负数 → 1.0/0 抛异常（可在回调里校验并返回 successful=False 拒绝）

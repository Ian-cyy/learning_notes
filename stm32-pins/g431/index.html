④ 硬件设计注意事项（G4 与 F1/F4 的差异）

  • 供电：VDD/VSS 各 4 对（15/16、31/32、47/48、63/64），VDD=1.71–3.6V（推荐 3.3V，宽压）；VDDA（29）与 VSSA（27）必须连接，保证 ADC 精度；VREF+（28）为 ADC/DAC 参考。
  • VREF+ 兼作 VREFBUF_OUT：内部基准缓冲可输出 2.048 / 2.5 / 2.9V，VREF+ 启用 VREFBUF 时需在外部接 1µF 滤波电容。
  • 时钟：HSE 主晶振在 PF0-OSC_IN / PF1-OSC_OUT（4–48MHz，常用 8MHz）——注意与 F1（PD0/PD1）和 F407（PH0/PH1）位置不同；LSE 32.768kHz 在 PC14/PC15；另有内部 HSI16 与 HSI48（供 USB/RNG）。
  • 启动：BOOT0 复用 PB8（无独立 BOOT0 脚），启动模式由选项字节 nBOOT0 / nBOOT1 决定（默认从主 Flash），建议用 CubeMX 配置；PB8 启动后建议配为非模拟模式以降低漏电。
  • 复位：NRST 复用在 PG10（7），低有效，内置上拉，建议外接 100nF；经选项字节可把该脚释放为普通 GPIO（PG10）。
  • 调试：复位后 PA13(SWDIO)/PA14(SWCLK)/PA15(JTDI)/PB3(JTDO)/PB4(JTRST) 被调试占用，内置上下拉（PA13/PA15/PB4 上拉、PA14 下拉）；不用 JTAG 时通过 DBGMCU/复用配置释放为 GPIO。
  • 5V 容限标注体系（与 F1/F4 不同）：G4 用 FT / TT / FT_c / FT_f / FT_fa / TT_a / FT_u 等精细标注。模拟脚（TT_a / FT_a）如 PA0-7、PB0-2、PC1/PC5 等严禁接 5V；FT_c（PB4/PB6）为 USB Type-C PD 引脚可耐 5.5V；FT_f 为 Fm+ 快速 I2C 引脚（PC8/PC9 等）。
  • PC13/PC14/PC15：备份域电源开关供电，输出驱动仅 3mA、速度≤2MHz，不要用来驱动 LED 等大电流负载。
  • USB：PA11=USB_DM、PA12=USB_DP（FT_u 结构），由内部 HSI48 提供 48MHz，无需外部晶振即可 USB；CRS 可自动校准 HSI48。
  • UCPD1（Type-C PD）：PB4=CC2、PB6=CC1（内置 5.1k 下拉，死电池支持），PA9=DBCC1、PA10=DBCC2；CC 下拉受 UCPD1_DBDIS 位控制。
  • 模拟资源（电机/信号链强项）：2×ADC（12bit、5Msps、双模式）、DAC1_OUT1/2（PA4/PA5）、3×OPAMP（同相/反相/跟随）、4×COMP、VREFBUF、ADC1_IN17 可测 VBAT（1/3 分压，VBAT 内置充电电路 VBRS 选 1.5k/5k）。
  • 定时器：TIM1/TIM8 高级定时器（6 通道互补 PWM，电机控制）；TIM2/3/4 通用 + TIM6/7 基本 + TIM15/16/17；LPTIM1 低功耗定时器。
  • 与 F407 差异：无 FSMC、无 QUADSPI、无 HRTIM（G431 限定）；新增 FDCAN1（CAN FD）、UCPD1、CORDIC/FMAC 数学加速、DAC/OPAMP/COMP；内核 M4F 带 FPU。
  • 无 VCAP：与 F407 不同，G431 内部稳压器无需外接 VCAP 滤波电容。
  • 复位后 I/O 状态：G4 复位后大部分 I/O 处于模拟输入状态（与 F1/F4 的浮空输入不同），编程时注意上电即配置。
  • 复用配置：每个 GPIO 有两组复用寄存器（GPIOx_AFRL/AFRH，每引脚 4bit 选 AF0–AF15），比 F1 的 AFIO 更灵活；建议用 STM32CubeMX 可视化配置。

④ 硬件设计注意事项

  • 供电：VDD（24/36/48）接 2.0–3.6V（推荐 3.3V）；VSS（23/35/47）接地；VDDA（9）与 VSSA（8）必须连接，保证 ADC 精度；VBAT（1）接备份电池或 VDD。
  • 与 F4 不同：F103 无 VCAP 引脚（内核稳压器内置，无需外接滤波电容）；内核为 Cortex-M3 无 FPU；复位后 PD0/PD1 用作主晶振 OSC_IN/OSC_OUT。
  • 时钟：PD0（5）= HSE 晶振输入、PD1（6）= HSE 晶振输出（4–16MHz，常用 8MHz）；PC14（3）/PC15（4）= LSE 32.768kHz；不用外部晶振（用内部 HSI 8MHz）时，PD0/PD1 可通过 AFIO 重映射为 CAN_RX/CAN_TX。
  • 启动：BOOT0（44）+ BOOT1（PB2，20）：00→主闪存，01→系统存储器（串口 ISP 引导），11→SRAM。BOOT0 需外接 10k 下拉，默认从 Flash 启动。
  • 复位：NRST（7）低有效，建议外接 100nF 到地；有内部上拉。
  • 调试：默认 SWD（PA13=SWDIO，PA14=SWCLK）；JTAG 占用 PA15/PB3/PB4。不用 JTAG 时通过 AFIO 释放为普通 GPIO。
  • PC13/PC14/PC15：由电源开关供电，输出驱动能力仅 3mA、速度≤2MHz，不要用来驱动 LED 等大电流负载。
  • 5V 容限（FT）：PA8–PA15、PB2–PB15（除 PB5）、PD0/PD1 为 FT 可直连 5V 逻辑；PA0–PA7、PB0/PB1 为模拟脚（TTa），严禁直接接 5V。
  • USB：PA11=USB_DM、PA12=USB_DP（内置 D+ 上拉），需 48MHz 时钟（由 HSE 倍频或 HSI 校准产生）。
  • 重映射：F103 大量外设可重映射到备用引脚（如 USART1 可到 PB6/PB7、CAN 可到 PB8/PB9 等），通过 AFIO_MAPR 寄存器配置，注意与 JTAG 引脚冲突。
  • 复用配置：GPIO 复用功能通过 GPIOx_CRL/CRH 寄存器配置（F1 无 AFR 寄存器，与 F4 不同），建议用 STM32CubeMX 可视化配置。
数据来源：ST 官方《STM32F103x8/xB Datasheet》（DS5319 Rev 18）Table 5 与《STM32F10xxx Reference Manual》（RM0008）· 复用以 RM0008 为准
